# Contributing

This is my personal portfolio, so I'm not looking for new features. Small fixes are welcome though.

## Good ways to help

- Report a bug, a broken link or a typo by opening an issue. Please mention your browser, device and screen size, and what you expected to happen.
- Send a pull request for a small fix (accessibility, layout bug on a certain screen size, spelling).

## Before you send a pull request

1. Fork the repository and make a branch for your change.
2. Run the site locally (`python3 -m http.server 8000`) and check your change in Light Mode and Dark Mode, on a wide screen and on a phone-sized window.
3. Keep it simple. The project has no framework and no dependencies, and I'd like to keep it that way.
4. Don't change my personal information (name, links, email, certificates, text). Send me an issue instead if something there is wrong.
5. Describe what you changed and why in the pull request.

## Using this site as a template

You are free to use the code for your own portfolio under the MIT License. Please replace all personal content with your own: name, photos, certificate images, resume link, email, project text, and the website address in `index.html`, `robots.txt`, `sitemap.xml` and `llms.txt`. The README has a table showing where each of these lives.
