# Contributing

Thanks for stopping by. This is my personal portfolio, so I'm not looking for new features (the light bulb already has enough personality). Small fixes, on the other hand, are very welcome.

## Ways to help

- **Report a bug, a broken link or a typo** by opening an issue. Tell me your browser, device and screen size, and what you expected to happen. "It looks weird" is a start, but a screenshot is better.
- **Send a pull request** for something small: an accessibility fix, a layout bug on a particular screen size, a spelling mistake.

## Before you send a pull request

1. Fork the repository and make a branch for your change.
2. Run the site locally (`python3 -m http.server 8000`) and check your change in Light Mode and Dark Mode, on a wide screen and in a phone-sized window.
3. Keep it simple. The project has no framework and no dependencies, and I would like it to stay that way.
4. Leave my personal information alone (name, links, email, certificates, text). If something there is wrong, open an issue and I will fix it.
5. Say what you changed and why in the pull request. One or two sentences is plenty.

## Using this site as a template

You are free to use the code for your own portfolio under the MIT License. Please swap all of the personal content for your own: name, photos, certificate images, resume link, email, project text, and the website address in `index.html`, `robots.txt`, `sitemap.xml` and `llms.txt`. The [maintenance notes](docs/MAINTENANCE.md) have a table showing where each of these lives.

My certificates and photos are not included in the license, so please do not leave them in. Having my face on your portfolio would be confusing for everyone, including me.
